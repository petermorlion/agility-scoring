## Learnings
- **Android PDF libraries:** Only pure managed .NET libraries survive APK packaging (zero native dependencies allowed)
- **PDFsharp characteristics:**
  - XGraphics API is low-level (more verbose than QuestPDF/iText7)
  - System fonts (Arial) unavailable on Android; use Helvetica
  - No high-level table API — must draw manually with XRect positioning
  - Namespace conflict: `PdfSharp.PageSize.A4` vs MAUI `Page.Size`
- **Font style enum:** `XFontStyleEx` in PDFsharp 6.x (not `XFontStyle`)
